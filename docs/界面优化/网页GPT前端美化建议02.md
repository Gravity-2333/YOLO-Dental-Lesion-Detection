你上一轮已经完成了一版 Gradio 前端美化，但当前效果仍然不好：页面虽然卡片化了，但整体仍然很丑，甚至比原来更像“套了 CSS 的 Gradio Demo”。这次请基于当前代码继续优化，不要重写后端功能，不要破坏推理、导出、病例、AI 问答和设置保存逻辑。

当前问题非常明确：

1. 卡片套卡片太多，所有区域都被白色卡片、边框、阴影包起来，视觉很碎。
2. Gradio 默认组件痕迹太重，很多 label 变成蓝色小标签贴在组件左上角，像调试界面，不像正式产品。
3. 左侧操作栏太窄，上传框、参数设置、按钮、滑条被挤压，甚至出现横向滚动条。
4. 参数区视觉很乱，Radio、Checkbox、Slider、Textbox 的默认样式没有统一。
5. 三张图片预览虽然并排了，但空状态很丑，只显示一个破图标，没有正式的空状态。
6. 检测框表格、辅助建议、质量提示、报告导出之间仍然像堆组件，没有形成清晰的信息层级。
7. AI 问答页虽然变成了卡片，但对话区过大、过空，整体像没做完。
8. 病例记录页控件仍然很像表单堆叠，缺少病例管理页面的结构感。
9. 设置页尤其难看：内容卡片过宽、控件很少、保存按钮漂在右下角，页面像半成品。
10. “全卡片化”方向是错误的，不要继续把所有东西都包卡片。

这次优化目标：

把界面从“卡片堆叠的 Gradio Demo”改成“轻量医疗 AI 检测工作台”。

关键词：
- 去卡片套卡片；
- 减少边框和阴影；
- 去掉小蓝标签泛滥；
- 提升布局比例；
- 强化工作台感；
- 保持干净、克制、专业；
- 不要花哨；
- 不要全部白盒子；
- 不要让控件像调试面板。

一、整体视觉方向

请改成更接近现代 AI Workbench / 医疗影像分析工作台的布局：

页面结构应该是：

顶部：
- 产品名、标题、说明、状态 badge；
- 不要太高；
- 不要强烈装饰。

主导航：
- 检测工作台 / AI 问答 / 病例记录 / 设置；
- 采用简洁 underline tab；
- 不要每个 Tab 都厚重卡片化。

主体：
- 使用一个大的浅色工作区 surface；
- 内部通过分区、留白、细分割线组织内容；
- 不是每个小控件都包成卡片。

视觉基调：
- 背景：#F5F7FB 或 #F7F9FC；
- 主内容 surface：#FFFFFF 或非常浅的 #FBFCFE；
- 边框尽量少，颜色 #E6EAF0；
- 阴影非常轻，只给主工作区，不给每个小卡片都加阴影；
- 主色蓝色 #2563EB；
- 橙色尽量不用，除非表示警告或非常少量强调；
- 不要使用很多蓝色小标签；
- 字体大小、间距、控件高度统一。

二、检测工作台重新调整

当前检测工作台最丑的问题是左侧太窄、控件挤压、卡片过多。请改成以下布局：

整体比例：
- 外层使用一个 workspace 容器；
- 左侧控制区宽度 360px 到 420px，不要低于 360px；
- 右侧结果区占剩余宽度；
- 两栏间距 24px；
- 页面最大宽度建议 1320px 或 1360px。

左侧控制区：
不要再用很多嵌套卡片。建议只有两个主要区域：
1. 上传与执行
2. 推理参数

上传与执行区域：
- 顶部用普通标题文字“上传影像”，不要用蓝色小胶囊 label；
- 上传框高度控制在 260px 左右；
- 上传框空状态要更正式：
  图标 + “拖拽牙科影像到此处” + “支持常见图片格式”
- “开始分析”按钮放在上传框下方，主按钮，可以满宽，但高度控制在 42px 到 46px；
- 不要让上传组件内部底部图标、边框显得很突兀，尽量通过 CSS 弱化。

推理参数区域：
- 标题“推理设置”；
- 模型模式和推理设备用 segmented control 风格，不要像默认 radio；
- 置信度和 IoU 放成两行紧凑配置：
  左侧 label，右侧数值输入，下面 slider；
- 修复当前 slider 横向滚动条问题，绝对不能出现横向滚动条；
- CLAHE 做成一行开关：
  左侧“CLAHE 增强”
  下方一行小字“低对比度影像可开启”
- 不要给每个 label 加蓝色背景。

右侧结果区：
顶部三图预览改成一个整体影像区，而不是三张孤立卡片。
建议：
- 外层一个 image-stage；
- 内部三列：
  原图 / 模型输入 / 检测结果；
- 每列标题在图片上方，普通文本即可；
- 空状态使用淡灰背景 + 图标 + “等待上传”；
- 不要只显示破图标；
- 三图高度统一，建议 220px 到 260px；
- 图片区域边框轻，不加重阴影。

检测框表格：
- 放在影像区下面；
- 标题“检测框”；
- 表格要轻量，表头背景淡灰，边框不要太重；
- 空表格时显示“暂无检测结果”，不要只显示空表头。

辅助建议和质量提示：
- 两列布局；
- 不要厚重卡片；
- 可以用 result-section 分区；
- 标题普通加粗；
- 内容区浅灰背景或白底细边框；
- 空状态：
  辅助建议：“完成检测后生成辅助建议”
  图像质量：“等待影像质量评估”

报告导出：
- 放在右侧结果区底部的工具条；
- 一行内：
  [报告路径输入框，占满] [报告导出按钮]
- 不要再单独包一个很大的白卡片；
- 按钮不可用时使用 disabled 样式。
