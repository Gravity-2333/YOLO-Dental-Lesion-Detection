# AI问答页面布局修复报告

## 问题描述

**发现时间**: 2026年6月3日
**问题页面**: AI问答标签页
**具体问题**: "发送"和"导出对话"按钮没有和前面的输入框齐平，布局不美观

## 问题分析

### 原因定位

AI问答页面使用了 `.path-row` CSS类来布局"导出路径"输入框和"导出对话"按钮。

**CSS定义**:
```css
.chat-card .path-row {
  grid-template-columns: minmax(0, 1fr) 120px !important;
}
```

这个定义是正确的（2列网格布局），但是缺少了子元素的宽度约束，导致按钮可能超出预期宽度。

### 受影响区域

1. **继续提问区域**: 输入框 + "发送"按钮
2. **导出对话区域**: "导出路径"输入框 + "导出对话"按钮

## 修复方案

### CSS修复

在 `assets/workbench.css` 中添加精确的布局约束：

```css
.export-toolbar .path-row,
.chat-card .path-row {
  grid-template-columns: minmax(0, 1fr) 120px !important;
}

.chat-card .path-row > .block,
.chat-card .path-row > .form,
.export-toolbar .path-row > .block,
.export-toolbar .path-row > .form {
  flex: 1 1 0 !important;
  min-width: 0 !important;
}

.chat-card .path-row button,
.export-toolbar .path-row button {
  width: 120px !important;
  min-width: 120px !important;
  max-width: 120px !important;
}
```

### 修复要点

1. **输入框区域**: 设置 `flex: 1 1 0` 和 `min-width: 0`，确保输入框可以弹性填充剩余空间
2. **按钮宽度**: 强制设置按钮宽度为 120px，使用 `width`、`min-width`、`max-width` 三重约束
3. **网格布局**: 保持 `grid-template-columns: minmax(0, 1fr) 120px` 的2列布局
