# 字体和下拉框修复报告

## 修复日期
2026年6月3日

## 问题描述

### 问题1: 路径输入框字体显示异常
**现象**: 各种目录框（模型路径、存储路径等）中的英文路径显示很怪异
**原因**: 未指定字体，使用了系统默认字体（可能是等宽字体或其他不适合的字体）

### 问题2: 下拉框箭头被文字遮挡
**现象**: 设置-模型选择页面里的"使用选中模型"按钮左侧的下拉框，选择箭头被文字阻挡
**原因**: 下拉框输入区域的padding-right不足，没有为箭头图标预留足够空间

---

## 修复方案

### 1. 全局字体设置

为整个应用设置微软雅黑字体：

```css
body,
.gradio-container {
  background: var(--app-bg) !important;
  color: var(--text-main) !important;
  font-family: "Microsoft YaHei", "微软雅黑", Arial, sans-serif !important;
}
```

### 2. 输入框和文本区域字体

为所有输入框、文本区域和下拉框设置字体：

```css
textarea,
input,
select {
  border-radius: var(--radius-sm) !important;
  min-width: 0 !important;
  font-family: "Microsoft YaHei", "微软雅黑", Arial, sans-serif !important;
}
```

### 3. 路径输入框专用字体

为路径显示框添加明确的字体设置：

```css
.path-output textarea,
textarea[aria-label="报告路径"],
textarea[aria-label="导出路径"],
textarea[aria-label="批量导出路径"],
textarea[aria-label="模型目录"],
textarea[aria-label="存储目录"],
textarea[aria-label="主模型路径"],
textarea[aria-label="对比模型路径"] {
  font-size: 0.88rem !important;
  font-family: "Microsoft YaHei", "微软雅黑", Arial, sans-serif !important;
  /* ... 其他样式 ... */
}
```

### 4. 下拉框箭头空间修复

为下拉框添加右侧padding，确保箭头不被遮挡：

```css
/* 修复下拉框箭头被遮挡问题 */
.gradio-container .dropdown,
.gradio-container select,
.gradio-container .wrap.svelte-1gfkn6j {
  position: relative !important;
}

/* 确保下拉框有足够的padding为箭头留空间 */
.gradio-container select,
.gradio-container .dropdown .wrap input {
  padding-right: 36px !important;
}

/* 下拉框容器 */
.gradio-container .dropdown {
  min-width: 0 !important;
}

/* 下拉框选项容器 */
.gradio-container .dropdown .options {
  max-height: 300px !important;
  overflow-y: auto !important;
}
```
