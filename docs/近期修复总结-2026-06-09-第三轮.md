# 近期修复总结：批量导出一致性与模型选择状态

## 修复范围

本轮继续检查批量检测、结果导出和模型选择页的状态一致性，重点修复上一轮批量对比接入后的下游导出遗漏。

## 主要修复

1. 修复批量对比模式导出时，`detections.csv` 只写主模型结果的问题；现在会带上 `model` 列，并逐模型写入检测框。
2. 修复批量导出的 `detections.json` 只保存主模型结果的问题；现在每张图片会保留 `models` 明细，同时兼容保留顶层主模型 `detections`。
3. 修复批量导出 `summary.txt` 仍显示单个 `model`、总框数只统计主模型的问题；现在会统计所有模型结果、各类别数量和各模型处理数量。
4. 修复设置页模型下拉初始值总是第一个文件的问题；当已保存主模型存在于扫描结果中，会优先选中已保存主模型。
5. 修复设置页帮助文字仍写“只扫描 .pt 文件”的过期提示，改为说明扫描受支持模型文件。
