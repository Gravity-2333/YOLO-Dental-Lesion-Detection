# 项目文档索引

本文档是 `docs/` 目录入口，用来快速定位项目资料。后续新增文档默认使用中文命名，并按主题放入对应目录；只有外部工具强依赖固定英文文件名时，才保留英文命名并在这里说明原因。

## 项目进度

- `项目进度/AI协作进度记录.md`：AI 协作过程、关键修改和阶段性进展。
- `项目进度/优化变更日志.md`：界面与功能优化变更日志。
- `项目进度/任务总结.md`：阶段任务总结。
- `项目进度/阶段性最终总结.md`：早期阶段的最终总结报告。
