# Gradio UI 本地验证说明

本说明用于在本机使用真实牙片样例验证 Gradio 检测工作台。不要把真实牙片样例提交到 GitHub。

## 样例放置

- 可将本地牙片放在 `local_samples/` 或 `private_samples/`。
- `.dcm` 文件、`local_samples/`、`private_samples/` 已加入 `.gitignore`。
- 如果需要提交截图，只提交已经脱敏且允许公开的 `screenshots`，不要提交原始私有牙片。

## 启动

```powershell
mamba activate yolo
python app.py
```

默认访问：

```text
http://127.0.0.1:7860
```

## 验证项目

1. 单图拖拽替换
   - 在“单张分析”上传一张本地牙片并运行分析。
   - 直接拖拽第二张图片到同一输入框，确认旧结果被清空，新图片可直接分析。

2. CLAHE 开关
   - 关闭“使用 CLAHE 增强后推理”运行一次。
   - 开启该选项再运行一次。
   - 对比“实际送入模型的图”，确认默认路径没有强制增强，开启后才显示增强后的入模图。

3. 批量上传
   - 在“批量分析”一次选择多张本地牙片。
   - 点击“批量分析”，确认完成后下拉框出现每张图片名称。

4. 逐张查看
   - 在批量结果下拉框中切换图片。
   - 确认原始上传图、实际送入模型的图、检测结果图、检测框表格和建议内容同步切换。

5. 结果导出
   - 批量分析完成后点击“一键导出批量结果”。
   - 默认确认 ZIP 位于用户目录下的 `YOLO-Dental-Lesion-Detection/exports/`。
   - 如果在“对话记录”设置中更换了“存储位置（数据根目录）”，确认 ZIP 位于新路径下的 `exports/`。
   - 如果系统用户目录无写入权限，应用会尝试使用项目同级的 `YOLO-Dental-Lesion-Detection-user-data/` 作为兜底数据目录。
   - 打开 ZIP，检查 `images/`、`detections.csv`、`detections.json`、`suggestions/`、`summary.txt` 是否存在且可读。

6. 默认建议
   - 关闭“启用 AI 建议与问答”。
   - 运行单图或批量分析。
   - 确认建议包含“本结果仅供辅助参考，不能替代专业牙科医生诊断。”，并按检测类别和置信度给出关注或复查建议。

7. AI 建议开关
   - 开启“启用 AI 建议与问答”。
   - 填写 OpenAI-compatible Chat Completions 的 `base_url`、模型和 API Key 设置。
   - 可在“AI 建议 Prompt”中查看默认 prompt，或改成自己的提示词。
   - 点击“测试接口”，确认极小请求返回反馈。
   - 运行检测后，确认 AI 只基于检测结果文本生成建议，不上传牙片图片。

8. 存储路径迁移
   - 在“对话记录”设置中把“存储位置（数据根目录）”改到一个新的本地目录。
   - 原路径为空时，确认旧空目录被删除。
   - 原路径有 `conversations/` 或 `exports/` 内容时，确认内容被迁移到新路径下对应目录。

## 注意

- 不要用本地验证结果反向调整模型参数或训练策略。
- 不要基于测试集表现修改界面默认阈值。
- 本工作台输出仅供辅助参考，不能替代专业牙科医生诊断。
