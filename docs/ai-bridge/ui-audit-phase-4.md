# 第四阶段 UI 截图审计

更新时间：2026-07-09

## 1. 截图逐页评价

### 01-workbench-home.png

检测工作台首屏结构稳定，顶部标题、安全声明、主导航、四步流程和左右工作区都能正常显示。主路径已有“上传影像、开始分析、查看结果、保存或导出”，但“选择模型”没有在首屏流程中显式出现；模型选择实际位于设置页，演示人员第一次打开页面时不够直观。

明显问题：

- 高级推理参数在左侧首屏下方露出，容易和主操作同等抢视觉。
- 结果区三个空图框只有默认图片图标，空状态可用但不够友好。
- 四步流程缺少“选择模型”提示，和本阶段要求的演示路径略有偏差。

### 02-workbench-model-dropdown.png

模型下拉框能打开，箭头没有被遮挡，功能可用。问题主要是模型路径很长，展开列表信息密度高；选中项虽然能省略显示，但用户难以快速判断 baseline、优化模型、best/last 权重之间的差异。

明显问题：

- 长路径占用大量视觉空间。
- `best.pt`、`last.pt`、预训练权重和候选模型混在同一列表中，普通用户不容易分辨演示推荐项。
- 模型依赖信息没有和下拉选择强绑定，C2f-Faster-lite 的外部依赖需要更醒目。

### 03-workbench-after-example-or-upload.png

上传和检测后的主流程能走通，三张图和类别图例正常显示。检测结果没有出现错误态，布局保持稳定。结果图区域信息层级比较清晰，但检测表、辅助建议和导出区在首屏以下，需要滚动查看。

明显问题：

- 完成检测后的“下一步导出报告/保存病例”提示不够突出。
- 类别说明卡片可读，但占横向空间较多。

### 04-ai-chat.png

AI 问答页整体干净，默认建议文本已包含安全声明。页面顶部说明较短，对“不会上传牙片，只发送检测文本摘要”的隐私边界不够显眼；API 配置入口也不够明确。

明显问题：

- 空对话状态尚可，但隐私与安全边界需要前置展示。
- 用户不知道 AI 问答需要先到设置页配置接口。

### 05-cases.png

病例记录页结构完整，保存区、筛选区和详情区分离。页面说明已提到保存检测摘要和建议，但没有在首屏明确强调“不自动保存原始牙片图片”和本地保存边界。

明显问题：

- 无病例时容易显得下方区域空。
- 病例字段的用途可以更清楚，尤其是病例编号、备注和筛选条件。

### 06-settings.png

设置页模型卡片比高级路径更友好，baseline 和推荐模型有初步区分。当前问题是模型卡片仍缺少“当前默认模型”“当前选中”“依赖状态”和“演示推荐”的强提示；C2f-Faster-lite 的 `../yolov8-train` 依赖没有出现在卡片附近。

明显问题：

- 模型卡片信息还偏简略，无法一眼判断默认、baseline、优化和依赖状态。
- 高级路径区隐藏是合理的，但展开后长路径仍较密。

### 07-mobile-workbench.png

移动端没有明显横向溢出，主导航通过“更多”折叠可用，四步流程按两列排列。问题是首屏垂直信息较长，上传区域需要继续滚动；关键按钮和文件框宽度总体稳定。

明显问题：

- 标题、说明、流程和上传卡片之间垂直间距略大。
- 上传区高度偏高，移动端首屏只能看到一部分上传框。

## 2. 信息层级问题

1. “选择模型”没有进入检测工作台首屏主路径。
2. Settings 中模型选择能力强，但演示推荐、默认模型、依赖状态不够显眼。
3. AI 问答和病例记录的隐私边界没有前置成稳定提示。
4. 空状态仍偏 Gradio 默认展示，专业辅助系统感可以更强。

## 3. 移动端问题

- 当前没有发现明显横向溢出。
- 需要压缩移动端顶部和流程区间距。
- 下拉框、路径框、表格仍需保持 `min-width: 0` 与横向滚动策略。
- 上传框和图像结果区在移动端应减少最小高度，避免首屏被单个控件占满。

## 4. 设置页模型信息密度

设置页模型卡片总体不算过密，但关键信息不够明确。高级下拉框展开后路径信息很密，适合高级用户，不适合作为演示主入口。第四阶段应优先强化卡片，而不是继续增加下拉框内容。

## 5. 检测工作台主路径是否清晰

基本清晰，但需要补上“选择模型”与“演示推荐”的提示。建议把主路径改成：

```text
1. 上传影像 → 2. 选择模型 → 3. 开始分析 → 4. 查看并导出
```

由于模型选择实际在设置页，本阶段只做提示和入口说明，不改变推理流程和组件顺序。

## 6. 医疗辅助软件专业风格

整体风格克制、干净，安全声明存在，符合医疗辅助软件基础要求。需要继续加强：

- 隐私边界。
- 非诊断边界。
- 模型依赖和展示建议。
- 空状态的专业说明。

不建议加入营销式 hero、强装饰背景或过度动画。

## 7. 优化优先级

### P0

1. 强化检测工作台主路径，补充“选择模型”和演示推荐提示。
2. 强化设置页模型卡片，展示 baseline、优化模型、默认模型、当前选中、可用/缺失/依赖缺失。
3. 在 AI 问答和病例记录页前置隐私与安全边界。

### P1

1. 优化空结果区、空对话和无病例状态说明。
2. 压缩移动端顶部、流程卡片和上传区高度。
3. 减少高级模型路径展开后的视觉压迫，保留省略和 tooltip。

### P2

1. 建立更正式的截图回归脚本。
2. 后续可把模型选择与展示模式做成更明确的演示配置入口。
3. 继续优化 Word 报告视觉模板。

1. 是否需要把模型选择直接放到检测工作台，而不是只在设置页提示。
