# 近期修复总结：导出下载、设置持久化与交互鲁棒性

## 修复范围

本轮主要围绕 Gradio 工作台的下载导出、设置保存、病例记录、AI 问答体验和前端对齐细节做阶段性收口。

## 主要修复

1. 修复运行中切换存储目录后，批量导出、单图报告和聊天导出文件可能无法直接下载的问题，保存设置或生成导出时会同步 Gradio 下载白名单。
2. 修复显示设置没有持久化的问题，`允许对比模型模式` 和 `显示参数分析摘要` 会写入配置；关闭对比模式时会同步强制主工作台和设置页回到单模型。
3. 修复病例记录连续保存可能覆盖、Windows 保留文件名不安全、病例选择可被构造路径读取的问题。
4. 修复类别名大小写、下划线、短横线等格式差异导致专属建议回退的问题，并优化 AI 超时、连接失败时的中文提示。
5. 修复聊天发送失败后输入被清空、当前消息未参与请求上下文的问题；失败时保留输入，成功后再清空。
6. 优化按钮和输入框对齐，处理长模型名遮挡下拉箭头的问题，并减轻导出区域工具栏的视觉块感。
