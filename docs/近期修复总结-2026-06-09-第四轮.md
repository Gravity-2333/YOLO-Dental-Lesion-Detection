# 近期修复总结：存储迁移、病例详情与模型选择状态

## 修复范围

本轮继续测试设置迁移、病例保存与病例详情展示，以及模型选择页的初始状态一致性。

## 主要修复

1. 修复数据存储目录切换到旧目录内部时，旧数据不会迁移的问题；现在会迁移旧目录内容并跳过新目录自身，避免递归移动。
2. 修复病例保存时 `case_id` 或 `case_note` 为空值可能触发 `.strip()` 异常的问题。
3. 优化病例详情中的复杂摘要展示，尤其是对比模型的 `模型结果` 不再显示成一整串列表字面量。
4. 修复模型文件下拉优先选中已保存主模型时，相对路径配置无法匹配扫描出的绝对路径的问题。
