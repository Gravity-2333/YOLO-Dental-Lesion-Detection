# 给 Codex 的总任务说明

## 一、任务背景

这是一个基于已训练 YOLO 牙齿病变检测模型的前台识别系统。当前项目已经能完成单图检测、批量检测、检测结果展示、图像质量提示、AI 建议、病例记录和报告压缩包导出。

后续开发目标不是训练模型，也不是复训练模型，而是提升前台识别系统的普通用户体验、报告导出能力、批量统计能力、病例管理能力和结果解释能力。

## 二、严禁偏离的方向

请不要实现以下功能：

1. 模型复训练。
2. 主动学习。
3. 在线标注平台。
4. 自动加入训练集。
5. 训练数据集管理。
6. GPU 服务器训练调度。
7. 医院 PACS 深度集成。
8. 多用户权限系统。
9. 诊所收费、保险理赔、预约管理。

这些内容不属于当前项目范围。

## 三、推荐开发顺序

请按以下优先级逐步实现，不要一次性大改所有内容。

### 第一优先级

1. 正式 Word 报告导出。
2. 批量检测结果总览。
3. 置信度等级解释。
4. 结果图放大查看与局部裁剪。
5. 病例记录搜索、筛选、删除、导出。
6. 图像质量检测增强。

### 第二优先级

1. 模型信息说明页。
2. 模型卡片式选择。
3. 检测历史记录。
4. 批量报告合并导出。
5. AI 建议结构化。
6. 检测结果图例与类别说明。

### 第三优先级

1. 演示样例库。
2. 牙位粗定位。
3. 检测框显示开关。
4. 结果图片单独下载。
5. 界面新手引导。
6. 异常处理提示优化。

## 四、代码组织要求

不要继续把所有业务逻辑堆到 app.py 中。建议新增以下模块：

```text
src/dental_detection/reporting.py
src/dental_detection/batch_summary.py
src/dental_detection/result_levels.py
src/dental_detection/image_quality.py
src/dental_detection/case_store.py
src/dental_detection/history_store.py
src/dental_detection/model_info.py
src/dental_detection/visualization.py
```

app.py 主要负责 Gradio 组件布局和事件绑定，具体业务逻辑放到模块中。

## 五、中文要求

面向用户的界面文字、报告文字、导出文件名、按钮文字、表格列名应使用中文。

代码中的注释必须使用中文。

下载文件名和导出文件名也应尽量使用中文，例如：

```text
牙齿病变辅助识别报告_20260609_153000.docx
批量检测总览_20260609_153000.json
检测结果图_病例001_20260609_153000.png
```

## 六、安全要求

所有报告、AI 建议、病例记录中必须保留：

```text
本结果仅供辅助参考，不能替代专业牙科医生诊断。
```

不要输出：

1. 确诊。
2. 一定患病。
3. 必须治疗。
4. 处方。
5. 药物剂量。
6. 自行用药建议。

AI 功能仍然只接收检测结果文本，不要上传原始牙片图片给外部 AI 接口。

## 七、验收要求

每次实现一个功能后，至少检查：

1. 单图检测是否正常。
2. 批量检测是否正常。
3. 报告导出是否正常。
4. 病例记录是否正常。
5. AI 建议是否正常。
6. 设置保存是否正常。
7. 新功能是否能处理无检测框情况。
8. 新功能是否能处理中文文件名。
9. 新功能是否不会暴露 API Key。
10. 新功能是否没有引入训练、复训练或标注平台逻辑。

请每次修改后给出中文提交说明，说明修改了哪些文件、实现了哪些功能、如何测试。
