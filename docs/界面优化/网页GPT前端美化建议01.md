你现在负责优化我这个 Gradio 前端界面。请先完整阅读当前项目代码，找到 Gradio 界面构建文件、CSS 文件、事件绑定函数和配置保存逻辑，然后在不破坏现有 YOLO 推理、模型选择、病例保存、AI 问答、导出报告等后端功能的前提下，重点做一次“现代医疗 AI / SaaS 工作台风格”的前端美化和信息架构优化。

项目背景：
这是一个“牙齿病变区域识别”系统，前端使用 Gradio 搭建。功能包括：
1. 检测工作台：单张分析、批量分析；
2. AI 问答；
3. 病例记录；
4. 设置：检测显示、模型选择、AI 建议、对话记录、高级接口；
5. 模型推理支持单模型 / 对比模型；
6. 支持 CPU / CUDA GPU；
7. 支持置信度、IoU、CLAHE、导出报告、保存病例等功能。

本次任务不是重写功能，而是优化界面视觉、布局、文案和交互层级。请不要把后端推理逻辑改坏，不要擅自删除现有功能，不要修改模型权重路径解析、推理函数、保存病例函数、导出函数的核心逻辑。重点是改 Gradio Blocks 布局、组件排列、CSS、按钮尺寸、提示文案、帮助信息呈现方式。

请把当前界面优化成现代 SaaS / AI Workbench / 医疗辅助检测工作台风格，而不是普通调试 Demo 页面。

整体风格参考：

建议视觉变量：

二、必须解决的现有问题

1. 删除或收纳冗余说明文字

当前界面有很多直接暴露给用户的长说明，例如：
- “三点按钮会打开当前数据目录；Web 前端不能直接读取 Windows 原生选择器返回的绝对路径。”
- “第一版固定使用 OpenAI-compatible Chat Completions /v1/chat/completions。请求字段只使用 model、messages、temperature、max_tokens。”

这些内容不应该直接出现在主界面。请改成以下方式：
- 主界面只保留短文案；
- 详细解释放到“？”帮助按钮、折叠的 gr.Accordion，或者单独的“帮助 / 使用说明”区域；
- 对普通用户无用的技术实现说明默认隐藏；
- 设置页中的说明文字每条尽量控制在 20 个汉字以内；
- 技术细节可以放入“高级说明”折叠面板，默认关闭。

例如：
原文：
“三点按钮会打开当前数据目录；如需更换位置，请在输入框中填写目标目录后保存设置。”
改成：
主界面显示：“存储目录”
旁边放一个小的“？”或“帮助”按钮，点击 / 展开后再解释。

原文：
“第一版固定使用 OpenAI-compatible Chat Completions /v1/chat/completions。请求字段只使用 model、messages、temperature、max_tokens。”
改成：
主界面显示：“接口兼容 OpenAI Chat Completions”
详细字段说明放入“接口说明”折叠面板，默认关闭。

2. 优化按钮尺寸

当前很多按钮文字很短，却独占整行，非常丑。请统一按钮规则：

- 主操作按钮可以较宽，例如“开始分析”“批量分析”；
- 但普通按钮不能无脑占满整行；
- “刷新模型列表”“测试模型文件”“恢复默认目录”“...” 这类按钮应该是紧凑按钮；
- “...” 必须是小型 icon button 或窄按钮；
- “保存设置”可以是主要按钮，但不要每个分区都放一个巨大满宽按钮；
- 同一组操作按钮应横向排列；
- 如果按钮只是辅助动作，使用 secondary / ghost 风格；
- 禁止短文字按钮横跨整页。

建议按钮样式：
- primary：蓝底白字，用于“开始分析”“批量分析”“保存设置”；
- secondary：浅灰背景深色文字，用于“刷新”“测试”“恢复默认”；
- ghost/icon：透明或浅灰，用于“...”“复制”“全屏”“帮助”；
- disabled：浅灰，不要过重。

3. 路径输入框和“...”按钮必须在同一行

这是重点。当前有些路径输入框和“...”按钮被排到下一行，体验很差。请全部改成现代 Web 表单常见结构：

一行内：
[ 路径输入框，占满剩余宽度 ] [ ... 小按钮 ] [ 可选：恢复默认 / 打开目录 ]

例如设置页“存储位置（数据根目录）”：
- label 在上方；
- 下方一行横向布局；
- 左侧 Textbox 占满；
- 右侧 “...” 小按钮；
- 再右侧可以放“恢复默认”紧凑按钮；
- 不要让按钮换行到下面；
- 不要让“...”按钮占半屏宽度。

模型目录、报告路径、导出路径、病例存储目录等所有路径类控件都按这个规则统一。

可以封装一个视觉结构：
PathInputRow:
- label
- gr.Row(elem_classes=["path-row"])
  - gr.Textbox(scale=12)
  - gr.Button("...", scale=1, elem_classes=["icon-btn"])
  - 可选 gr.Button("恢复默认", scale=2, elem_classes=["secondary-btn"])

如果 Gradio scale 不好控制，就用 CSS 针对 elem_classes 做 flex 布局。
