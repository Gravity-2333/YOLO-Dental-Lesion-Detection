# 近期修复总结：模型选择、批量对比与超大图标注一致性

## 修复范围

本轮继续测试核心检测链路和工作台交互，重点修复模型文件选择、批量检测模式和超大图预处理带来的体验与逻辑问题。

## 主要修复

1. 修复模型文件下拉框只扫描 `.pt` 的问题，现在会列出后端实际支持的 `.pt`、`.onnx`、`.engine`、`.mlmodel`、`.mlpackage`、`.torchscript`。
2. 修复模型选择、刷新和测试提示仍写死 `.pt` 的体验问题，避免用户选择其他支持格式时看到冲突文案。
3. 修复批量分析忽略“允许对比模型模式”的逻辑漏洞；开启对比模式时，批量结果会保存主模型和对比模型两组检测结果。
4. 修复超大图片预处理缩放后，原图、模型输入和检测结果尺寸可能不一致导致标注框错位的问题。
